🔌 PORT MANAGEMENT
═══════════════════════════════════════════════════════════════

Kill Port 19006 (Windows):
  netstat -ano | findstr :19006
  taskkill /PID <PID> /F

Kill Port 19006 (Mac/Linux):
  lsof -ti:19006 | xargs kill -9

Kill All Node Processes (Windows):
  taskkill /F /IM node.exe

Kill All Node Processes (Mac/Linux):
  killall node

🧹 CACHE CLEARING
═══════════════════════════════════════════════════════════════

Clear Metro Cache:
  cd mobile
  rm -rf .expo
  rm -rf node_modules/.cache

Clear All Caches (Windows):
  cd mobile
  rmdir /s /q .expo
  rmdir /s /q node_modules\.cache

Clear All Caches (Mac/Linux):
  cd mobile
  rm -rf .expo node_modules/.cache
  rm -rf $TMPDIR/metro-*
  rm -rf $TMPDIR/haste-*

🎯 COMMON ISSUES & FIXES
═══════════════════════════════════════════════════════════════

Issue: White Screen
Fix:
  1. Open browser console (F12)
  2. Check for errors
  3. npm run start:web:clean

Issue: WebSocket Connection Failed
Fix:
  - This is normal, app still works
  - WebSocket only for hot reload
  - Can be safely ignored

Issue: Backend Connection Failed
Fix:
  1. Check backend is running
  2. Verify http://localhost:8000
  3. Check CORS settings

Issue: Metro Bundler Crash
Fix:
  1. Kill all node processes
  2. npm run clear
  3. npm run start:web:clean

Issue: Port Already in Use
Fix:
  1. Kill process on port 19006
  2. npm run start:web:clean
